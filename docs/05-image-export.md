# 05 图片导出

把**当前激活合成**的当前帧画面，快速导出成图片或复制到剪贴板。

---

## 入口

在搜索框右侧有一个**下载图标**，把鼠标悬停在它上面，会弹出导出菜单：

| 菜单项 | 说明 |
| ------ | ---- |
| 存为 PNG | 保存为 `.png` |
| 存为 JPG | 保存为 `.jpg`（透明区域以白底合成） |
| 存为 Webp | 保存为 `.webp` |
| 存入剪贴板 | 不保存文件，直接把画面复制到系统剪贴板 |

> 免费版**仅支持 PNG**；其余三项为灰色不可点，悬停会提示「免费版仅支持 PNG 导出，请升级解锁」。

---

## 保存到哪里

点击保存项时，根据当前状态自动决定：

| 情况 | 保存行为 |
| ---- | -------- |
| 工程**已保存**，且点击时**没有按住 Alt** | 自动保存到**工程文件所在目录**，文件名为 `<合成名>.<扩展名>` |
| 工程**尚未保存**，或点击时**按住 Alt** | 弹出「另存为」对话框，自行选择位置 |

补充说明：

- 自动保存时如果已有同名文件，会依次生成 `合成名_1.png`、`合成名_2.png`…，不会覆盖旧文件；
- 对话框模式会记住上次保存的目录，下次打开时默认定位到那里；
- 选择「存入剪贴板」时不会弹出任何对话框。

> 弹出文件对话框前，控制台会先自动隐藏，这是正常行为。
> 保存完成后重新按 `Ctrl + 空格` 呼出即可。自动保存（不弹对话框）时窗口保持显示，
> 成功后会提示「保存成功」，失败时会提示具体原因。

---

## 导出的是什么画面

导出内容是**当前激活合成在当前时间位置的整帧画面**，与合成分辨率一致。

所以使用前请：

1. 先打开（激活）一个合成；
2. 把时间指针移动到想要导出的那一帧。

**常见错误提示**：

- `没有激活的合成` —— 当前没有打开任何合成；
- `激活的不是合成` —— 当前激活的是素材/图层等其它项目，请先打开合成。

---

## 相关说明

- JPG 格式不支持透明通道，导出时透明区域会与**白色**背景混合；
- 需要透明背景时请使用 PNG；
- 导出会占用一点渲染时间，画面较复杂的合成请稍等。
