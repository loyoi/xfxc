# 11 快捷键速查

## 键盘

| 按键 | 作用 |
| ---- | ---- |
| `Ctrl + 空格` | 呼出 / 收起控制台（全局快捷键，可在 设置 → 强制快捷键 中关闭） |
| `Esc` | 关闭控制台窗口（窗口锁定时无效）；在设置/编辑等页面中返回上一页 |
| `↑` / `↓` | 上下选择搜索结果（首尾循环滚动） |
| `Enter` | 执行当前选中的结果 |
| `1` ~ `9`、`0` | **搜索框为空时**：直接执行快捷面板前 10 个按钮 |
| `Tab` / `Shift + Tab` | **搜索框为空时**：切换面板 Tab 页（存在多个面板时） |

> 开始输入文字后，数字键就是普通的输入字符，不会再触发面板按钮。

## 鼠标

| 操作 | 作用 |
| ---- | ---- |
| 点击搜索结果 | 执行该条目 |
| 右键搜索结果 | 菜单：**📍 添加到按钮...** / **☆ 添加到收藏**（已收藏为 ★ 取消收藏） |
| 右键面板格子 | 菜单：**编辑** / **删除**（格子为空时只有编辑） |
| 点击面板上方标签 | 切换面板 Tab 页 |
| 点击标签栏右侧 `▾` | 面板太多放不下时，展开其余 Tab 列表 |
| 点击搜索框右侧齿轮 | 打开设置 |
| 悬停搜索框右侧下载图标 | 展开图片导出菜单（PNG / JPG / Webp / 剪贴板） |
| `Alt` + 点击导出项 | 强制弹出「另存为」对话框（而不是自动保存到工程目录） |
| 点击🔒 / 🔓 | 锁定 / 解锁窗口（锁定后失焦不隐藏） |
| 点击状态栏 ⟳ | 刷新数据 |
| 点击状态栏 ☁ | 进入云同步设置（开启同步后显示） |
| 长按空白处约 **0.35 秒** 后拖动 | 移动控制台窗口 |
| 长按面板按钮约 **0.5 秒** 后拖动 | 调整按钮顺序（拖拽排序） |

## 其他交互提示

- 呼出控制台后，**搜索框自动获得焦点**，直接输入即可；
- 执行任意结果后窗口**自动收起**（窗口锁定时保留）；
- 快捷面板拖拽排序时，状态栏会显示「已进入拖拽排序」，
  源格黄色高亮、目标格蓝色高亮，松手完成排序。

> 备注：`Ctrl + 空格` 与 macOS 系统「选择上一个输入源」快捷键冲突，
> Mac 用户需先在系统设置中取消后者，详见 [01 安装与更新](01-install.md)。
