# 03 快捷面板

把常用的效果、脚本、预设、字体做成按钮，点一下就用 —— 不用每次重新搜索。

搜索框为空时，控制台中间显示的就是**快捷面板**；一旦开始输入，则切换为搜索结果列表。

---

## 面板布局

- 每个面板（一个 **Tab 页**）是 **4 行 × 5 列 = 20 个按钮**。
- 按钮左上角有编号：`1` ~ `9`、`0`、`11` ~ `20`。
- 搜索框为空时，键盘数字键 `1`~`9`、`0` 可直接执行**前 10 个**按钮（其余按钮用鼠标点击）。

## Tab 页

| 操作 | 方式 |
| ---- | ---- |
| 切换页 | 点击面板上方的标签；页多时用右侧 `▾` 溢出菜单；键盘 `Tab` / `Shift + Tab` 循环切换（搜索框为空时生效） |
| 管理页 | 设置 → 数据管理 → **Tab 管理** |

**Tab 管理页**（每行一个 Tab）：

- 每行显示：名称、按钮数量；点击「切换」把该页设为当前显示页；
- 鼠标悬停时出现操作按钮：`✏`（重命名）、`🗑`（删除，仅当存在多个 Tab 时）、`▲`/`▼`（调整顺序）；
- 底部输入框填写名称，按回车或点「添加」新增 Tab（留空会自动命名为 `Tab N`）；
- 删除 Tab 会弹出确认框。

> 面板数量限制：**免费版仅 1 个 Tab 页（共 20 个按钮）**；完整版最多 **128 个**。

---

## 添加按钮

最常用的方式是从搜索结果直接添加：

1. 搜索到目标条目；
2. 在结果上点**右键 → 📍 添加到按钮...**；
3. 进入编辑页：默认会放到当前面板的**第一个空位**，可在「Tab / 按钮位置」下拉中改成其它位置（下拉会显示 `序号 - 已有名称` 或 `序号 - 无`）；
4. 需要的话修改名称、类型、分类；
5. 点**保存**。

也可以右键点击面板上**任意格子 → 编辑**，从空白开始手动创建按钮。

## 编辑 / 复制 / 删除按钮

在面板中**右键点击某个格子**：

| 菜单项 | 说明 |
| ------ | ---- |
| 编辑 | 打开编辑页；通过修改「Tab / 按钮位置」下拉，可以把它**移动或复制**到其它位置（标题会相应显示「编辑按钮 / 复制按钮」） |
| 删除 | 删除该按钮（需确认） |

编辑页底部的**保存 / 取消**按钮用于提交或放弃修改；按 `Esc` 等同取消。

### 编辑页字段说明

| 字段 | 说明 |
| ---- | ---- |
| Tab | 目标面板页 |
| 按钮 | 目标格子位置（编号 1~20） |
| 名称 | 按钮上显示的名称 |
| 类型 | `effect (效果)`、`file (文件)`、`eval (脚本)`、`font (字体)`、`expr (表达式)` |
| 分类 | 自定义分组文字（可选） |
| 命令内容 | 该按钮实际执行的内容，随类型不同（见下表） |

| 类型 | 命令内容填什么 | 执行效果 |
| ---- | -------------- | -------- |
| effect (效果) | 效果标识（从搜索添加时自动填好） | 给选中图层应用该效果 |
| file (文件) | 文件路径，支持路径变量 | 按扩展名分发：`.ffx` 应用预设 / `.jsx`、`.jsxbin`、`.js` 执行脚本 / 其他导入素材 |
| eval (脚本) | 一段 ExtendScript 代码 | 直接执行这段代码 |
| font (字体) | 字体 PostScript 名称（从搜索添加时自动填好） | 设置到选中的文本图层 |
| expr (表达式) | 一段表达式代码 | 设置到选中图层的选中属性 |

**File 类型的辅助按钮**（在「命令内容」标题旁）：

- **打开目录**：在文件管理器中定位到该路径（路径变量会先展开；文件不存在会提示）；
- **格式化路径**：自动去掉引号、把 `\` 统一为 `/`，用于清理从别处粘贴来的路径。

### 路径变量

File 类型的路径支持以下变量，换机器或换 AE 版本也能正确找到文件：

| 变量 | 含义 |
| ---- | ---- |
| `%AE_PRESETS%` | AE 自带预设根目录 |
| `%USER_PRESETS%` | 用户预设目录 |
| `%AE_SCRIPTS%` | AE 自带脚本根目录 |
| `%USER_SCRIPTS%` | 用户脚本目录 |
| `./` | 用户数据目录（`文档\LoYoi\xfxconsole`） |

把鼠标悬停在「支持路径变量」提示上，可以看到各变量在**当前机器**上解析到的实际路径。

## 拖拽排序

想调整按钮顺序时，直接在面板上拖：

1. 在某个按钮上**按住约 0.5 秒**（长按期间不要移动鼠标）；
2. 按钮格变为高亮后，拖动到目标格子松开即可完成排序；
3. 拖动过程中，状态栏会显示「已进入拖拽排序」。

说明：

- 拖动时**源格黄色高亮、目标格蓝色高亮**；
- 空白格子不能拖起，但可以作为**落点**（把按钮拖到空格上即移动过去）；
- 长按后松手不会误触发按钮执行。

---

## 面板数据在哪

按钮、Tab 名称、排列顺序都保存在用户数据目录的 `config.json` 中
（`文档\LoYoi\xfxconsole`），因此可以随 [07 云同步](07-webdav-sync.md) 在多台机器间同步。
