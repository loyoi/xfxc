# 07 云同步（WebDAV）

把配置、面板、收藏、用户脚本等数据同步到自己的 **WebDAV 服务器**，
让多台机器共用同一套玄如意设置。**免费版也可使用。**

**打开方式：设置 → 数据管理 → 云同步**；也可以点击状态栏的 ☁ 图标直达。
页面顶部有 **配置** / **同步日志** 两个页签。

---

## 配置页

| 字段 | 说明 |
| ---- | ---- |
| 服务器URL | WebDAV 服务地址（如 `https://dav.example.com/dav/`） |
| 用户名 | WebDAV 账号 |
| 密码 | WebDAV 密码 |
| 命名空间 | 用于在同一账号下隔离多套数据；默认 `xfxconsole`，**一般无需修改** |

点击**保存**后配置生效（会提示「配置更新成功」）。

**测试连接**：保存前可先测试，结果有三种：

- `连接成功，云端已有数据（远端版本 N）`；
- `连接成功，云端暂未初始化`；
- `连接测试失败: 具体原因`（网络、账号密码、地址错误等）。

> 配置（含密码）保存在**本机**，不会同步到云端或其它机器。

**开启自动同步**（配置页底部勾选）：

- 勾选后提示「已开启，将自动同步」；
- 之后数据（配置、脚本等）发生变更时会**自动同步**一次；
- 底部同时显示同步状态：`未在同步` / `同步中...` / `同步失败: 原因`。

> 同步范围为「**文档/LoYoi/xfxconsole**」整个文件夹（Windows：
> `C:\Users\<你>\Documents\LoYoi\xfxconsole`）。

---

## 同步日志页

顶部一排按钮：

| 按钮 | 说明 |
| ---- | ---- |
| 刷新 | 重新读取本机同步记录 |
| 清除历史 | 清空同步记录（仅日志，不影响数据） |
| 上传 | **破坏性操作**：以本地内容完全覆盖云端，并删除云端多余文件（有确认框） |
| 下载 | **破坏性操作**：以云端内容完全覆盖本地，并删除本地多余文件（有确认框） |
| 强制同步 | 立即执行一次完整的双向同步（合并双方改动） |

日志格式为 `[日期 时间] ✓/✗ 摘要`，失败的记录会附带 `；错误: 原因`；暂无记录时显示「暂无同步记录」。

**上传 / 下载怎么选？**

- 本机数据是权威、云端想被覆盖 → 用**上传**；
- 云端数据是权威、本机想恢复成云端的样子 → 用**下载**；
- 只是想让两边合并（日常使用）→ 用**强制同步**（或开启自动同步后交给它自动处理）。

## 第一次连接已有云端数据

当检测到**云端已有数据**时（例如在新机器上第一次开启同步，或云端已有其它机器上传的数据），
会弹出确认框：

| 选项 | 说明 |
| ---- | ---- |
| 使用云端数据 | 以云端为准，覆盖本地对应文件 |
| 保留本地上传 | 以本地为准，把本地数据上传到云端 |

> ⚠️ 这是**方向性**的选择，建议先确认哪边的数据才是自己要保留的。
> 选择前也可以先分别做一次「上传」或「下载」的快照备份。

---

## 文件冲突处理

如果同一个文件在**本地和云端都被修改过**，会弹出「文件冲突」页面，
逐个文件选择处理方式：

| 处理方式 | 说明 |
| -------- | ---- |
| 合并 | 由同步引擎尝试合并双方改动 |
| 采用云端 | 用云端版本覆盖本地 |
| 双份 | 两边都保留（生成一份副本） |
| 保留本地 | 用本地版本覆盖云端 |

也可以使用底部的 **全部采用云端** / **全部保留本地** 批量处理，
最后点**应用处理**执行。仍有未处理的文件时会提示「仍有 N 个冲突未处理」。

---

## 同步范围说明

| 会同步 | 不同步（每台机器各自独立） |
| ------ | -------------------------- |
| `config.json`（收藏、面板、扫描开关等） | 界面语言 |
| 效果别名 / 拼音覆写文件 | 强制快捷键开关 |
| 用户数据目录中的脚本等文件 | 附加扫描源（glob 规则） |
|  | WebDAV 配置本身（含账号密码） |

> 也就是说：换机器后语言与快捷键需要重新设置一次，其余配置自动带过去。
