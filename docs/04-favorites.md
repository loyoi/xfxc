# 04 收藏夹

收藏用来标记**高频使用的条目**，它们会：

- 在搜索结果中**排在最前面**；
- 支持用 `fav:` 前缀只搜收藏（见 [02 搜索与执行](02-search.md)）；
- 行尾显示金色 ★ 标识。

---

## 收藏 / 取消收藏

在搜索结果上点**右键**：

| 菜单项 | 说明 |
| ------ | ---- |
| ☆ 添加到收藏 | 把该条目加入收藏 |
| ★ 取消收藏 | 把该条目移出收藏 |

收藏状态会立即生效，无需额外保存。

---

## 管理收藏夹

打开 **设置 → 数据管理 → 收藏管理**（页面标题为「管理收藏夹」）。

列表里每一行显示：**序号、名称、对应的命令内容**（灰色小字）。

**鼠标悬停**在某行上，会出现两个按钮：

| 按钮 | 说明 |
| ---- | ---- |
| ✏ | 重命名：行内出现输入框 |
| 🗑 | 删除：从收藏夹移除（立即生效） |

重命名输入框的操作：

- 按**回车**或点 **✅** 保存；
- 点 **❌** 放弃修改；
- 名称**留空保存**会恢复该条目的原始名称（即清除别名）。

---

## 给条目起别名（改名的妙用）

收藏夹改名不只是"换个称呼"：**改名后，搜索结果里的名称会显示为 `原名 (别名)`，
而且这个别名同样可以被搜索到**。

例如某款插件效果 `SuperGlow` 只有英文名，把它改名为 `辉光`：

- 结果显示为 `SuperGlow (辉光)`；
- 以后输入 `辉光` 或它的拼音（`huiguang`、`hg`）都能直接搜到。

> 如果该效果本身已有内置中文别名，两个别名会一起显示为 `原名 (内置别名 | 你的别名)`。
> 对文件类条目，如果别名与文件名相同，就不会重复显示括号内容。

这是给**没有中文名**的第三方插件效果补中文名的快捷方式；
如果想批量自定义效果别名，也可以在 [06 数据扫描](06-data-scan.md) 里使用覆写文件。

---

## 数据位置

收藏列表（含自定义别名）保存在用户数据目录的 `config.json` 中
（`文档\LoYoi\xfxconsole`），可随 [07 云同步](07-webdav-sync.md) 在多台机器间同步。
