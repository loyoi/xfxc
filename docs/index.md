# 玄如意控制台 · 使用文档

**在 AE 里，用中文搜效果。**

按一下 `Ctrl + 空格` 呼出控制台，输入「高斯」或 `gsmh`，就能直接定位到 Gaussian Blur ——
不用记英文名，不用翻五层菜单。还可以把常用效果、脚本、预设、字体做成按钮面板，点一下直接用。

> 适用版本：**0.12.7** ｜ Windows / macOS ｜ 界面以简体中文为准
> 其他语言界面（繁體中文 / English / 日本語 / Русский）文案可能与本手册用词略有差异，以实际界面为准。

---

## 一分钟上手

1. **安装**：关闭 AE，把插件文件放进插件目录，重启 AE。（详见 [01 安装与更新](01-install.md)）
2. **呼出**：按 `Ctrl + 空格`，或从 AE 菜单 **窗口 → XFXConsole** 打开。
3. **搜索**：输入中文、拼音或英文，如 `高斯`、`gsmh`、`blur`。
4. **执行**：`↑` / `↓` 选择，`Enter` 执行；也可以直接鼠标点击结果。
5. **做成按钮**：在搜索结果上点右键 → **📍 添加到按钮...**，常用项就变成了面板按钮。

> 效果类条目会应用到**当前选中的图层**；脚本、预设、字体等也各有对应的执行方式，
> 详见 [02 搜索与执行](02-search.md)。
