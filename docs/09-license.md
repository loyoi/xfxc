## 在线许可（¥19.9）

在线许可绑定**邮箱账号**，支持在多台机器之间迁移。

### 激活步骤

1. 在「在线许可」页输入**邮箱**，点击**查询**；
2. 根据查询结果进入对应流程：

| 查询结果 | 接下来做什么 |
| -------- | ------------ |
| 已验证 | 显示 ✅「在线许可已激活」，重启控制台后生效 |
| 此号未入册（还没买过） | 弹出提示，点确定后**发送验证码到邮箱**；输入收到的 6 位验证码，点「验证购买」→ 自动打开付款页面；付款完成后回到本页重新查询验证 |
| 此机未授信（买过，但这台机器没备案） | 弹出提示，点确定后发送验证码；输入验证码，点「认证机器码」→ 提示「机器码备案成功，重启后生效」 |
| 账号已被封禁 | 显示封禁提示，请联系客服 |

> 在线许可**每次启动会联网校验**，请保持网络可用。

### 设备管理（仅在线许可）

在 **设置 → 许可方式** 行右侧点击**设备管理**：

| 操作 | 说明 |
| ---- | ---- |
| 查看设备列表 | 当前设备前有 ● 标记；未命名设备显示为「未命名设备」 |
| 编辑 | 修改设备名称（便于区分多台机器） |
| 删除 | 删除该设备的认证；之后可重新认证 |
| 刷新列表 | 重新拉取设备列表 |
| 增加设备数量 | 新购机器位：**9.9 元/位**，随账号永久有效；适合多台机器同时使用，避免频繁验证 |

> 一台设备 = 一个"机器位"。购买时附赠一机位；需要更多设备时可单独加购。
> 不用的设备建议删除认证，腾出机器位。

## 离线许可（¥9.9）

适合只需要在一台机器上使用、不想每次联网校验的用户。

**购买步骤**：

1. 打开「离线许可」页，点击**去购买页面**（<https://loyoi.com/product/xfxc-offline>）；
2. 页面上会显示本机的 **🔑 机器码**，把它发给卖家完成购买；
3. 收到 **🚀 激活码**后，粘贴到输入框，点击**激活**；
4. 提示「验证成功，关掉重开」后重启控制台即可。

**注意事项**：

- 一机一码，**仅限这一台电脑使用**；
- 更换硬件（主板等）会导致机器码变化，届时**需要重新购买**；
- **离线版不支持退款**，请确认适用后再购买；
- 如果页面提示「获取机器码失败」，请重启 AE 后再试。

## 免费许可

在「免费许可」页点击**开始免费使用**即可切换到免费版（提示「已切换为免费模式」）。

免费版部分高级功能不可用（面板数、导出格式、主题、附加扫描源），其余功能不受限制。

## 清理许可

**设置 → 许可方式 → 清理许可**：清除本机保存的许可信息并返回许可页面。
适用于更换账号、出售电脑前清除授权等情况。

> 在线许可清除后，换台机器可用同一邮箱重新查询激活；
> 离线许可清除后需要原激活码才能重新激活。
