# 10 常见问题

## 安装与启动

**Q：`Ctrl + 空格` 按了没反应？**

按顺序检查：

1. **macOS 用户**：`Ctrl + 空格` 与系统自带的「选择上一个输入源」冲突。
   前往 **系统设置 → 键盘 → 键盘快捷键 → 输入法**，取消勾选「选择上一个输入源」；
2. 打开 **设置 → 强制快捷键**，确认「开启」处于勾选状态；
3. 用 AE 菜单 **窗口 → XFXConsole** 试试能否打开：
   - 能打开 → 是快捷键冲突/开关问题，按上面步骤处理；
   - 打不开 → 插件没装上，见下一问。

**Q：重启 AE 后找不到 XFXConsole？**

- 确认插件文件在正确目录（Windows：`C:\Program Files\Adobe\Common\Plug-ins\7.0\MediaCore\LoYoi\`，
  macOS：`/Library/Application Support/Adobe/Common/Plug-ins/7.0/MediaCore/LoYoi/`）；
- 确认 AE 已完全退出后再启动（托盘里的 AE 进程也要退干净）；
- Windows 注意文件后缀是 `.aex`，不是 `.zip` 或重复后缀；
- macOS 可能因系统安全策略拦截未签名插件：在「系统设置 → 隐私与安全性」中允许加载；
  如仍被拦截，可在终端执行 `xattr -dr com.apple.quarantine <插件路径>` 解除隔离标记后再放入；

**Q：杀毒软件报毒/拦截？**

`.aex` 插件本质是 DLL，部分杀软会误报。把插件目录加入杀软白名单即可。

## 使用

**Q：免费版有水印或时间限制吗？**

没有。免费版可一直使用，只是面板数量限 1 个（20 个按钮）、图片导出仅 PNG、
不支持自定义附加扫描源、主题固定。

**Q：效果点了提示「请选择图层」？**

效果类操作需要先在合成中选中至少一个图层。选中图层后再执行即可。

**Q：点了脚本/预设没反应？**

命令由 AE 在**空闲时**执行：如果 AE 正在弹对话框、渲染或进行其它耗时操作，
命令会延后执行。稍等片刻，或切换一下 AE 窗口让它空闲下来。

如果提示「AE Script 不可用」，通常是 AE 刚启动、插件接口还没准备好，
等待几秒后重试；仍不行则重启 AE。

**Q：搜索结果显示不全 / 只显示 50 条？**

列表最多显示前 50 条。可以：

- 输入更多关键词缩小范围（多个关键词是「全部命中」的关系）；
- 用前缀限定类型，如 `e: 模糊`、`f: 黑体`；
- 看状态栏右下角的 `50/N 项` 了解总命中数。

**Q：能搜到条目，但执行后提示「文件不存在」？**

条目对应的文件被移动或删除了。点状态栏的刷新按钮重新扫描；
如果是自己添加的按钮，右键 → 编辑，修改「命令内容」里的路径。

**Q：为什么搜不到某个第三方效果？**

效果列表来自 AE 实际可用的效果。如果插件未安装成功、未加载，或该效果没有出现在
AE 的效果菜单中，就不会被收录。安装好插件后刷新一次数据即可。

**Q：我的 AE 是英文界面，还能用中文搜索吗？**

能——收录了中文别名的效果（大量第三方插件内置别名）可以直接用中文搜到。
AE 自带效果在英文界面下显示英文原名，用英文搜索即可；想给它固定一个中文名，
可以收藏后改名（见 [04 收藏夹](04-favorites.md)），或用覆写文件批量补名（见 [06 数据扫描](06-data-scan.md)）。

**Q：怎么给英文效果起中文名？**

- 单个条目：收藏它，再到 **设置 → 数据管理 → 收藏管理** 里重命名
  （别名会显示在搜索结果中，并且可以被搜索，详见 [04 收藏夹](04-favorites.md)）；
- 批量：编辑用户数据目录下的 `effect_alias_overwrite.txt`，详见 [06 数据扫描](06-data-scan.md)。

**Q：控制台窗口挡住操作 / 一失焦就消失？**

点击状态栏的 🔒 锁定窗口，锁定后失焦不会自动隐藏；再次点击解锁。
窗口位置可以按住空白处约 0.35 秒后拖动。

## 数据与同步

**Q：配置、按钮面板、收藏都在哪里？怎么备份？**

在 `文档\LoYoi\xfxconsole`（macOS：`~/Documents/LoYoi/xfxconsole`）文件夹中，
核心是 `config.json`。复制整个文件夹即可备份；
也可以开启 [07 云同步](07-webdav-sync.md) 自动多机同步。

**Q：换了电脑，配置怎么带过去？**

- 在线许可：在新机器用同一邮箱查询激活即可（可能需要先删除旧设备认证，或购买额外机器位）；
- 离线许可：绑定机器码，新机器需要重新购买；
- 配置：把 `文档\LoYoi\xfxconsole` 文件夹复制过去，或使用云同步。

**Q：云同步后语言/快捷键怎么没同步？**

界面语言、强制快捷键、附加扫描源是**本机设置**，故意不参与同步，每台机器各自独立。
其余配置（面板、收藏、覆写文件等）会同步。

**Q：本地和云端都改过文件，弹出了「文件冲突」怎么办？**

逐个文件选择「合并 / 采用云端 / 双份 / 保留本地」，或批量选择后点「应用处理」。
拿不准时选择「双份」最安全，两份都会保留。详见 [07 云同步](07-webdav-sync.md)。

**Q：上传/下载按钮是做什么的？会不会覆盖数据？**

它们是**破坏性镜像操作**：上传 = 本地完全覆盖云端；下载 = 云端完全覆盖本地。
点击时会有确认框。日常合并数据请用「强制同步」。

## 许可与售后

**Q：买了之后换电脑还能用吗？**

在线许可可以：在新机器上用同一邮箱重新查询激活；若机器位不足，可在
**设备管理**中删除不用的设备，或购买额外机器位（9.9 元/位）。

**Q：这是订阅制吗？**

不是，一次性买断，不用续费。

**Q：退款怎么办？**

完整版（在线许可）支持退款：通过许可页底部的 QQ 客服联系管理员办理。
离线版不支持退款。

**Q：卸载会删除我的配置吗？**

不会。卸载只需删除插件文件，数据仍保留在文档目录中；
如需彻底清除，再手动删除数据目录与注册表项（见 [01 安装与更新](01-install.md)）。
