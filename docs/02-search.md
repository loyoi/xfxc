# 02 搜索与执行

玄如意控制台的核心：把 AE 里深藏在菜单中的效果、脚本、预设、字体，变成**一次搜索直达**。

---

## 呼出与窗口行为

| 操作 | 说明 |
| ---- | ---- |
| 呼出 / 收起 | `Ctrl + 空格`（全局快捷键），或 AE 菜单 **窗口 → XFXConsole** |
| 失焦自动隐藏 | 点击 AE 主界面等窗口外部时，控制台自动收起 |
| 🔒 锁定窗口 | 点击底部状态栏最左侧的 🔒，锁定后**失焦不自动隐藏**，方便连续使用；再点一次解锁 |
| 编辑/配置页面 | 「编辑按钮」「数据预览」「云同步」等配置类页面打开期间，失焦不自动隐藏（便于长操作） |
| 关闭 | `Esc` 关闭窗口（锁定时 `Esc` 不生效）；在设置、数据预览、云同步、编辑按钮等页面中，`Esc` 为返回上一页 |

**拖动窗口**：在窗口的空白/背景/文字区域**按住约 0.35 秒**（可点击控件与输入框上不触发），
光标变为抓手后即可拖动窗口位置。

> 呼出后搜索框会**自动获得焦点**，直接开始输入即可。

---

## 搜索技巧

支持中文、拼音、英文混合搜索：一个条目可以用它的**显示名称、中文别名、全拼、拼音首字母**命中。

| 输入 | 能搜到 |
| ---- | ------ |
| `高斯` | Gaussian Blur（中文版 AE 中显示为「高斯模糊」） |
| `gsmh` | 同上，拼音首字母 |
| `gaosi` | 同上，全拼 |
| `gaussian` | 同上，英文原名 |
| `blur` | 名称中含 blur 的所有效果 |
| `jsx` | 名称里带 `.jsx` 的脚本类条目 |

- **效果类条目**：中文版 AE 中，AE 自带效果直接显示中文名（如 `高斯模糊`）；
  一直保持英文名的效果（如第三方插件）如果收录了中文别名，会显示为 `英文名 (中文别名)`。
  别名同样参与搜索，可在 [06 数据扫描](06-data-scan.md) 中通过覆写文件自定义。
- **文件类条目**的名称带后缀（如 `一键排版.jsx`），可以直接搜 `.jsx`、`ffx` 等后缀。
- **多个关键词**用空格分隔，条目必须**全部命中**才会显示（例如 `高斯 模糊`）。
- **收藏的条目排在最前**，其次按匹配程度排序。

## 前缀语法

在关键词前加上前缀，可以限定只搜索某一类内容：

| 前缀 | 含义 |
| ---- | ---- |
| `e:` | 只搜**效果** |
| `p:` | 只搜**文件**类（脚本、预设、工程等） |
| `f:` | 只搜**字体** |
| `fav:` | 只搜**收藏** |

**分隔符写法**：`:`、`：`、`;`、`；` 都可以，例如 `e:`、`e：`、`e;`、`e；` 等效。

**可以组合**：多个前缀按任意顺序叠加，例如：

```
fav: e: 高斯      → 收藏夹里的效果
e; fav; blur      → 同上
```

**只输入前缀**（不跟关键词）会列出该类的全部条目：

```
e:      → 列出所有效果
fav:    → 列出所有收藏
```

## 结果列表

- 列表最多显示**前 50 条**；命中更多时，状态栏右下角会显示 `50/N 项`，未超限时显示 `N 项`。
- 每一行的结构：

  ```
  [类型徽章]  名称（含中文别名）                      来源标签   ★
  ```

  - 徽章颜色区分类型（效果 / 文件 / 其他）；
  - 行尾小字是来源，例如「AE 效果 · 生成」；
  - 已收藏的条目会显示金色 ★。

- `↑` / `↓` 上下选择（首尾循环），`Enter` 执行选中的条目；也可以直接用鼠标点击。
- 执行后**窗口自动收起**（锁定状态时保留窗口）。

## 右键菜单

在任意搜索结果上点**右键**：

| 菜单项 | 说明 |
| ------ | ---- |
| 📍 添加到按钮... | 把该条目做成快捷面板按钮，跳到编辑页（详见 [03 快捷面板](03-quick-grid.md)） |
| ☆ 添加到收藏 | 收藏该条目（已收藏时显示 ★ 取消收藏） |

## 执行行为

不同类别的条目，执行时做的事情不同：

| 类别 | 执行行为 |
| ---- | -------- |
| 效果 | 应用到**当前选中的图层** |
| 文件 · 预设（`.ffx`） | 应用预设到当前选中的图层 |
| 文件 · 脚本（`.jsx` / `.jsxbin` / `.js`） | 运行脚本；位于 `ScriptUI Panels` 的脚本会以**可停靠面板**方式打开 |
| 文件 · 其他 | 作为素材**导入**到当前项目 |
| 字体 | 设置到当前选中的**文本图层** |
| 脚本（eval 类型按钮） | 执行自定义 ExtendScript 代码 |
| 表达式（expr 类型按钮） | 给选中图层的选中属性设置表达式 |

执行时可能看到的提示：

- `请选择图层` —— 效果类操作需要一个被选中的图层；
- `图层不支持或无此效果: xxx` —— 当前图层类型不支持该效果，或效果已失效；
- `文件不存在: xxx` —— 条目对应的文件已被移动或删除，请刷新数据或修改按钮路径。

> 命令由 AE 在**空闲时**执行。如果 AE 正忙（弹着对话框、渲染中等），命令会稍等片刻再执行；
> 如果长时间没反应，切换一下 AE 窗口让它空闲下来即可。

## 状态栏

底部状态栏从左到右依次是：

| 元素 | 说明 |
| ---- | ---- |
| 🔒 / 🔓 | 窗口锁定开关（锁定后失焦不隐藏） |
| 库: N | 当前可搜索的数据总量 |
| ⟳ 刷新 | 重新扫描数据；有变化时会弹出「刷新报告」，无变化则轻提示 |
| ☁ 云同步图标 | 仅在开启云同步后显示；点击进入同步设置页 |
| 结果数 | 右下角，显示当前搜索命中的条目数（超出上限时显示 `50/N 项`） |

搜索框为空时，中间区域会显示**按钮面板**而不是搜索结果，详见 [03 快捷面板](03-quick-grid.md)。
